POR QUE NO SE PODIA EJECUTAR:
=============================

PROBLEMA PRINCIPAL: RUTAS RELATIVAS
Ubicacion original del problema:
  String baseDir = "src/main/resources/";
  String json = new String(Files.readAllBytes(Paths.get(baseDir + "tablero.json")));

FALLA EN ESTOS CASOS:
  1. Cuando ejecutas el JAR → No encuentra src/main/resources/
  2. Cuando ejecutas desde otra carpeta → La ruta relativa no existe
  3. En distribucion → Los archivos no estan incluidos

SOLUCION APLICADA:
  Cambié a ClassLoader.getResourceAsStream() que:
  ✓ Lee desde el classpath (correcto para IDE y JAR)
  ✓ Busca en src/main/resources/ cuando está en IDE
  ✓ Busca en /resources/ dentro del JAR
  ✓ Siempre funciona sin importar donde se ejecute


PROBLEMAS SECUNDARIOS:
======================
1. Maven no estaba en el PATH
   → Pero ese es un problema del sistema, no del codigo

2. Imports innecesarios
   → Removidos: Files, Paths, IOException (no usados)

   → Ahora se cargan correctamente desde classpath
