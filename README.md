# Monopoly-Lite-Edition

## Concepto del Proyecto

Una versión simplificada y accesible del clásico juego de mesa Monopoly, implementada en Java como proyecto grupal de aprendizaje. La idea es crear un juego funcional que capture la esencia de Monopoly: competencia económica, estrategia inmobiliaria y suerte, pero en una escala más pequeña y manejable.

## ¿De Qué Va El Juego?

Los jugadores compiten en un tablero circular buscando acumular riqueza mediante la compra y alquiler de propiedades. Cada turno implica lanzar dados, moverse alrededor del tablero e interactuar con las casillas. Las propiedades generan ingresos pasivos a través del alquiler, mientras que eventos inesperados (cartas de suerte) y la posibilidad de ir a la cárcel añaden variabilidad al juego. El objetivo final: ser el último jugador en pie con dinero.

## Idea General

Este proyecto busca demostrar el dominio de conceptos fundamentales de programación orientada a objetos: encapsulación, herencia, polimorfismo y gestión de estado. Además, proporciona una base sólida para evolucionar hacia un juego completamente funcional con interfaz gráfica y jugabilidad refinada.
